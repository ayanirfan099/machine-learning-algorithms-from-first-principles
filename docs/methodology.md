# Methodology
Run `python -m first_principles.cli`. Seed 42 controls all generated data and splitting. Regression uses 400 Gaussian rows, 3 features, coefficients [1,-2,3], Gaussian noise SD 0.1 and 25% holdout. Classification uses 500 generated rows with two informative features, stratified 25% holdout and train-fitted StandardScaler. Hyperparameters are fixed in advance, not chosen using test metrics. Learning-rate curves use training loss only. Blobs contain 300 rows, three centers. PCA uses 200 rows, four features, the fourth correlated with the first. The CLI records actual elapsed wall time and metrics; environment package versions are in reproducibility.md. These data are generated under sklearn/NumPy APIs, with no third-party dataset redistribution.
